
# Academia Tech Palmas — Portal de Cursos

Aplicação front-end desenvolvida em **React + Vite** para a disciplina de Aplicativos Web (IFTO - Campus Palmas).

## Como executar o projeto

1. Instale as dependências:
   ```bash
   npm install
Nome completo: obrigatório, exigindo pelo menos 3 caracteres (ignorando espaços nas pontas).

E-mail: obrigatório, validado por expressão regular para garantir um formato válido (usuario@dominio.com).

Curso de interesse: seleção obrigatória de uma das opções disponíveis no campo <select>.

Senha: obrigatória, exigindo no mínimo 6 caracteres.

Confirmar senha: obrigatório e deve ser idêntico ao valor digitado no campo Senha
